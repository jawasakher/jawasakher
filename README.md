##  About Me

I'm a **Full-Stack Developer** focused on building modern web applications from the interface to the backend and database.

My development journey started with frontend development and grew into full-stack development through hands-on projects.

* ⚛️ Building modern interfaces with **React.js**
* 🎨 Creating responsive UI with **Tailwind CSS**
* ⚡ Developing backend services with **Node.js & Express.js**
* 🔌 Building and consuming **REST APIs**
* 🗄️ Working with **PostgreSQL & Prisma ORM**
* 🔐 Implementing **JWT authentication & password hashing**
* 🧩 Designing reusable components and structured application architecture
* 🚀 Deploying and maintaining real-world web applications
* 🧠 Learning through building, debugging, and improving real projects
