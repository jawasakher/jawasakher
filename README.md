### 🧠 About Me

* 💻 I'm a **Full-Stack Developer** focused on building modern web applications.
* ⚛️ I build responsive and interactive frontends using **React.js, JavaScript, and Tailwind CSS**.
* 🛠️ I develop backend applications and REST APIs using **Node.js and Express.js**.
* 🗄️ I work with databases and ORM technologies such as **PostgreSQL and Prisma**.
* 🔐 I've explored **authentication, password hashing, JWT, API integration, and backend architecture**.
* 🚀 My projects include a real estate platform, an AI chatbot, and an e-learning platform.
* 🎯 I care about **clean code, reusable components, responsive design, and practical problem-solving**.
* 🌱 I'm continuously improving my skills in **full-stack development, databases, and software engineering**.
* 📚 I believe in learning by building real projects and continuously improving them.
